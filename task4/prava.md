| Роль (RBAC)                                          | Права роли                                                                                                                                                                               | Группы пользователей                                       |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| **cluster-viewer** (ClusterRole)                     | Просмотр ресурсов кластера: `get/list/watch` для `namespaces`, `pods`, `deployments`, `replicasets`, `services`, `ingresses`, `events`, `configmaps` (без доступа к `secrets`)           | Операционная команда (менеджеры доменов), аудит, аналитики |
| **namespace-operator-sales** (Role в ns `sales`)     | Управление ресурсами приложения в `sales`: `get/list/watch/create/update/patch/delete` для `deployments`, `pods`, `services`, `ingresses`, `configmaps`, `jobs/cronjobs` (без `secrets`) | DevOps/инженеры эксплуатации домена Sales                  |
| **namespace-operator-tenant** (Role в ns `tenant`)   | То же самое, но только в `tenant`                                                                                                                                                        | DevOps/инженеры эксплуатации домена ЖКУ                    |
| **namespace-operator-finance** (Role в ns `finance`) | То же самое, но только в `finance`                                                                                                                                                       | DevOps/инженеры эксплуатации домена Finance                |
| **namespace-operator-data** (Role в ns `data`)       | То же самое, но только в `data`                                                                                                                                                          | DevOps/инженеры эксплуатации домена Data                   |
| **secret-reader-<ns>** (Role в каждом ns)            | Привилегия: `get/list/watch` для `secrets` в конкретном namespace                                                                                                                        | Специалист ИБ + платформенная команда (по необходимости)   |
| **platform-admin** (ClusterRole)                     | Полный доступ к кластеру: `*` на `*`, включая RBAC (`roles`, `rolebindings`, `clusterroles`, `clusterrolebindings`) и `secrets`                                                          | Платформенная команда / администраторы Kubernetes          |
